## 运行时优化

- 屏幕外图片使用原生延迟加载和异步解码；已有布局尺寸保留。
- 眼睛缓存瞳孔节点和几何位置，将布局读取与 SVG 写入分开；仅在鼠标、滚动或窗口变化后更新，停稳即停止 RAF，离屏或标签页隐藏时暂停，并响应减少动态效果设置。
- 导航和筛选提交使用 Next 客户端路由，避免整个文档重新加载。页尾关闭不必要的路由预取。
- 案例页共用背景在服务端生成静态 HTML，无需等待查询参数脚本执行后才显示。
- 首页日期校验直接引用纯日期函数，解除对全部人格内容数据的间接依赖。
- 按钮 hover / pressed 图片也通过统一素材映射加载，兼容部署 basePath。

原始素材保留在 `public/figma` / `public/design`。交付副本在 `public/optimized`，映射在 `src/lib/design/optimized-assets.json`。执行 `npm run optimize:assets` 可重新生成；字体转换脚本为 `scripts/optimize-fonts.py`，需要 `fonttools` 和 `brotli`。
